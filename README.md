# 🌷 Teachers' Day Message Card — Mr. Randy Bello

An interactive, book-style Teachers' Day greeting card built with **HTML, CSS, and JavaScript**.

**Teacher:** Mr. Randy Bello  
**Student:** Jasmin Merdegia

## ✨ Features

- 📖 3D book-style opening animation
- 💌 Personalized Teachers' Day message
- 🖼️ Built-in teacher photo with an option to upload another photo
- 🎵 Built-in audio with an option to upload another audio file
- ✏️ Live customization for teacher name, student name, message title, and message
- ❤️ Floating hearts and sparkle animations
- 🎉 Animated celebration burst when the card opens
- 📱 Responsive layout for desktop and mobile
- ⌨️ Keyboard support: Left/Right arrows to turn the card, Escape to close
- ♿ Respects `prefers-reduced-motion`
- 🚫 No framework or build process required

## 🚀 How to Run

1. Download or clone this project.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a modern browser.
4. Click **Open the Card** or click the cover.
5. Use **Customize Card** to change the names, message, photo, or audio.
6. Click **Play Music** to start the selected audio. Browsers normally require a user click before audio can play.

No `npm install`, server, or build command is required.

## 🖼️ Custom Photo

Click **Customize Card → Choose Photo**. The image is previewed immediately without changing the original project image.

## 🎵 Custom Audio

Click **Customize Card → Choose Audio**. Supported examples include MP3, M4A, WAV, OGG, and other browser-supported audio formats.

For a public GitHub deployment, use an audio file that you have permission to distribute publicly.

## 🌐 Upload to GitHub

1. Sign in to GitHub.
2. Create a **new public repository**, for example:
   `teachers-day-message-card`
3. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
   - the complete `assets` folder
4. Commit the files.
5. If desired, enable **GitHub Pages** in:
   **Settings → Pages → Deploy from a branch → main → / (root)**
6. GitHub will provide a public Pages URL after deployment.
